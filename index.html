MODEL NOTES / VERSION 0.1

From signals to evidence.

Your first investigation

  1. Select Approach target and watch the nominal response settle.
  2. Inject Stuck joint, then change J2 by 20°. Observe the sustained error.
  3. Hold command sets commands to true simulated positions. Pause freezes simulation time. A real system would not have this perfect position knowledge.
  4. Record evidence, alternative explanations and your next test. Export the report.
  5. Reset and compare sensor bias with signal oscillation.

Model and assumptions

A base yaw and two pitch joints position links of length 2 and 1.6 model units. Forward kinematics calculates the end-effector position. Limits: J1 ±180°, J2 ±80°, J3 ±120°. Normal response is a first-order lag with a 0.65-second time constant.

Stuck joint freezes true J2 motion. Sensor bias adds 8° to its measurement. Signal oscillation adds a 7° sinusoid at 0.8 Hz to the measurement; it is not a physical vibration model. Rendering uses true position; plots use measured signals.

The target is the position of pose [65°, 50°, −70°]. Approach target commands this known pose; there is no inverse kinematics or path planning. An alert requires J2 error above 5° continuously for 1.5 seconds. Oscillation may never meet that continuous threshold: absence of an alert does not establish nominal behaviour.

Limits and next steps

No orbital dynamics, inertia, contact, collisions, torque, communications delay or real spacecraft data. This is a desktop 3D projection, not AR/VR. Fault selection is visible for learning, not a blind assessment. Next steps: transient-aware detection, noise robustness, hidden-fault trials and collision checks.
